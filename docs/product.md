# Product

## 产品目标

构建一个基于 Injective 与 x402 的 Agent-to-Agent 交易原型。

卖方将一种资源、服务或产品及其预期价格和交易规则交给 Seller Agent；买方将需求、预算和交易规则交给 Buyer Agent。两个 Agent 通过 bid/ask 完成撮合，并在支付验证后完成交付：

- 买方获得约定的资源、服务或产品；
- 卖方获得可验证的支付结果。

## 黑客松 MVP

三日版本只打通一种交易标的的一条完整 happy path：

1. Seller Agent 发布包含标的、ask price 和交付条件的 Offer。
2. Buyer Agent 提交包含需求、bid price 和购买条件的 Request。
3. 两个 Agent 完成一次报价，并接受或拒绝。
4. 成交后通过 x402 发起支付，并在 Injective testnet 获得可验证凭证。
5. 支付验证成功后，Seller Agent 才交付资源。
6. Offer、Order、Payment 和 Delivery 通过同一订单 ID 关联。

首个版本采用单轮 bid/ask。复杂竞价、砍价和博弈不进入 MVP。

## 成功标准

- 可以从干净环境按 README 启动完整演示。
- 一次演示完整经过 `offer -> match -> payment -> delivery`。
- 支付结果可通过交易哈希或等价凭证验证。
- 买方可以验证已获得约定交付物。
- 重复请求不会产生重复订单、支付或交付。
- 支付失败时不会交付资源，并显示明确状态。
- 仓库和日志不包含私钥、助记词、访问令牌或其他真实凭据。

## 非目标

三日版本暂不实现：

- 支持多类资源的通用 marketplace；
- 多轮砍价、复杂博弈或最优撮合；
- 完整订单簿、流动性或价格发现机制；
- 主网真实资金交易；
- 完整身份、信用、争议、退款和生产运维体系；
- 对 Agent 自身工作或交易行为单独计价。
